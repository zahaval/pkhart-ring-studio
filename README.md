# PK HART — Birthstone Ring Studio

A 3D custom birthstone ring builder for PK HART Fine Jewelry, built by The Groundwork Co.

- 1–5 gold/rose/silver wraps, each with an optional birthstone (one shared carat for the top stones)
- A bottom row of up to three statement stones — oval, pear, heart or emerald cut, any stone, own carats, optional sideways set
- Stones are placed in PK HART's signature cascade; drag to turn the ring
- "Request this design" produces a full spec and opens the customer's email

Plain HTML + vendored three.js — no build step. Open `index.html` or serve the folder:

```bash
npx serve .
```

Live: https://pkhart-ring-studio.netlify.app (Netlify) · GitHub Pages from this repo.
